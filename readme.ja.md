# Awesome Websites to Explore [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> のんびりした午後にぴったりの Web の小さな片隅：おもちゃ、ゲーム、珍品、世界のライブ映像、読みもの。

**注目：** [Aubergine](https://github.com/thirstyeggplant/aubergine) - ブラウザの 1 枚のキャンバスにすべてのターミナルを置き、複数のコーディングエージェントを並べて動かし、どれがあなたを待っているかを確認できます。*（このリストの管理者が開発しています。）*

どれも普通のブラウザで動き、アカウントなしで始められ、無料で試せます。ほとんどは個人や小さなチームが作ったサイトです。気に入ったら作者に伝えてあげてください。

## どこかへ連れていって

ボタンを押せば、見たことのないサイトへ。StumbleUpon の精神はここに生きています。

- [Cloudhiker](https://cloudhiker.net) - 厳選されたサイトにランダムで飛びます。行き先を絞りたいならカテゴリも選べます。
- [The Useless Web](https://theuselessweb.com) - ボタン 1 つで、ネタ 1 つだけのサイトに飛ばされます。
- [Viralwalk](https://www.viralwalk.com) - 気分で絞り込んで、奇妙なページ、きれいなページ、忘れられかけたページへワープ。
- [Marginalia Explore](https://marginalia-search.com/explore) - 静かな Web 専門の検索エンジンが見つけた小さな個人サイトを巡ります。
- [Kagi Small Web](https://kagi.com/smallweb) - 独立系ブログの最新記事を 1 つずつ表示します。
- [indieblog.page](https://indieblog.page) - 個人ブログのランダムな記事へ連れていきます。
- [Wiby](https://wiby.me) - シンプルで昔風のページ専門の検索エンジン。「びっくりさせて」ボタン付き。
- [Neocities Browse](https://neocities.org/browse) - 現代版 GeoCities にある何千もの手作りサイト。タグ別や最近の更新順で見られます。
- [MapCrunch](https://www.mapcrunch.com) - 地球上のどこかのストリートビュー地点にランダムで降ろします。

## インタラクティブなおもちゃと解説

- [Neal.fun](https://neal.fun) - スケール、お金、宇宙、インターネットをテーマにした遊び心あるプロジェクト。海の最深部までスクロールするものなど。
- [The Pudding](https://pudding.cool) - 触って確かめられるデータで、ちょっと変わった疑問に答えるビジュアルエッセイ。
- [Bartosz Ciechanowski](https://ciechanow.ski) - 時計、カメラ、エンジンの仕組みを解説する長文記事。回したり分解したりできるモデル付き。
- [Nicky Case](https://ncase.me) - 信頼、不安、投票など難しい考えを、遊びながら理解できる小さな解説。
- [Explorable Explanations](https://explorabl.es) - ものを動かしながら学べるエッセイのディレクトリ。
- [Orb.Farm](https://orb.farm) - 生き物を入れて維持する小さな水槽。
- [Thisissand](https://thisissand.com) - 色とりどりの砂を注いで、ゆっくり層になる風景を作ります。
- [Silk](http://weavesilk.com) - ポインターで光る対称模様を描きます。
- [Zen Photon Garden](https://zenphoton.com) - 鏡と壁を置いて、光が跳ね返る様子を眺めます。
- [WebGL Fluid Simulation](https://paveldogreat.github.io/WebGL-Fluid-Simulation/) - 指やマウスで鮮やかな流体をかき混ぜます。
- [Falstad applets](https://www.falstad.com/mathphysics.html) - 波から回路まで、遊びながら触れる物理と電子工作。
- [Koalas to the Max](https://www.koalastothemax.com) - マウスを乗せて円を分割していくと、絵が浮かび上がります。
- [The Scale of the Universe 2](https://htwins.net/scale2/) - 知られている最小のものから宇宙の大きさまでズーム。
- [Experiments with Google](https://experiments.withgoogle.com) - コード、AI、音楽、地図を使った何百ものブラウザ実験。
- [VOLE.wtf](https://vole.wtf) - 発想豊かなスタジオが作った、ばかばかしい小さなゲームとおもちゃの山。

## 椅子に座ったまま旅をする

- [Radio Garden](https://radio.garden) - 地球儀を回して、止まった場所の地元ラジオを生で聴けます。
- [WindowSwap](https://www.window-swap.com) - 行くことのない街や村で、見知らぬ誰かの窓辺にしばし佇む。
- [Drive & Listen](https://drivenlisten.com) - 地元のラジオを流しながら、街の通りを動画でドライブ。
- [Virtual Vacation](https://virtualvacation.us) - 動画で街を歩き、走り、飛び回る。ライブカメラも見られます。
- [Yamanote.fun](https://yamanote.fun) - 東京の山手線に乗っている音を、駅ごとに。
- [Cities and Memory](https://citiesandmemory.com) - フィールド録音の世界地図。それぞれにアーティストによるリワークが添えられています。
- [Street View Fun](https://www.streetviewfun.com) - 地図撮影車が捉えた最も奇妙なもの。
- [Atlas Obscura](https://www.atlasobscura.com) - 世界中の不思議な場所を、地図と解説で。
- [The True Size Of](https://thetruesize.com) - 国を地図上でドラッグして、図法による大きさの歪みを確かめます。

## 地球と空をライブで

- [earth :: nullschool](https://earth.nullschool.net) - 今この瞬間の風、海流、大気質を表示するアニメーション地球儀。
- [Windy](https://www.windy.com) - 風、雨、波、嵐のライブ気象マップ。
- [LightningMaps](https://www.lightningmaps.org) - 落雷がリアルタイムで表示されます。
- [Flightradar24](https://www.flightradar24.com) - 今飛んでいる飛行機。クリックで追跡できます。
- [Stellarium Web](https://stellarium-web.org) - どこでも、いつでも、その場所の夜空。
- [NASA's Eyes](https://eyes.nasa.gov) - 3D で探査機や惑星と一緒に飛べます。
- [meow.camera](https://meow.camera) - 中国の猫用給餌器のライブカメラ。お腹をすかせた来客が立ち寄ります。

## 音楽とサウンド

- [Chrome Music Lab](https://musiclab.chromeexperiments.com) - 音楽理論を目に見える形にするシンプルな楽器と実験。
- [Typatone](https://typatone.com) - タイプした文字ごとに音が鳴ります。
- [Patatap](https://patatap.com) - キーを押すごとに音とアニメーションが流れます。
- [Incredibox](https://www.incredibox.com) - ビートボックス隊に音をドラッグして曲を作ります。
- [Multiplayer Piano](https://multiplayerpiano.com) - 知らない人たちと同じ部屋でピアノを弾く。
- [Online Sequencer](https://onlinesequencer.net) - グリッド上で曲を作って共有できます。
- [Every Noise at Once](https://everynoise.com) - 何千もの音楽ジャンルの地図。それぞれ試聴付き。
- [Radiooooo](https://radiooooo.com) - 国と年代を選んで、そこで流れていた音楽を聴く。
- [Music-Map](https://www.music-map.com) - バンド名を入れると、似た音のアーティストがわかります。
- [Gnoosic](https://www.gnoosic.com) - 好きなバンドを 3 つ挙げると、4 つ目を提案してくれます。
- [myNoise](https://mynoise.net) - スライダーで調整できる何百もの環境音。
- [A Soft Murmur](https://asoftmurmur.com) - 雨、風、焚き火、カフェの音をミックス。
- [Rainy Mood](https://rainymood.com) - 雨と雷、それだけ。
- [lofi.cafe](https://lofi.cafe) - ループするアニメーションにゆったりしたビート。
- [musicForProgramming();](https://www.musicforprogramming.net) - 集中するための長いミックス。

## すぐ遊べるゲーム

- [GeoGuessr](https://www.geoguessr.com) - ストリートビューの写真が世界のどこで撮られたかを当てる元祖。一部有料。
- [WorldGuessr](https://www.worldguessr.com) - ストリートビューで場所を当てる無料版。
- [TimeGuessr](https://timeguessr.com) - 写真が撮られた場所と年を当てます。
- [Globle](https://globle-game.com) - 推測がどれだけ近いかを手がかりに、その日の謎の国を探します。
- [Contexto](https://contexto.me) - 意味の近さを手がかりに、秘密の単語を見つけます。
- [Wiki Speedruns](https://wikispeedruns.com) - リンクだけを使って、Wikipedia の記事から記事へ競争。
- [The Endless Museum](https://theendlessmuseum.com) - リンクが扉になった 3D 美術館として Wikipedia を歩きます。
- [Little Alchemy 2](https://littlealchemy2.com) - 要素を組み合わせて何百ものものを発見。
- [Cookie Clicker](https://orteil.dashnet.org/cookieclicker/) - クッキーをクリックし、やがて代わりにクリックしてくれる帝国を築きます。
- [Kittens Game](https://kittensgame.com) - 猫の村を育てる、ゆっくりしたテキストゲーム。
- [Akinator](https://en.akinator.com) - 誰かを思い浮かべると、魔人がはい・いいえの質問で当てます。
- [Find the Invisible Cow](https://findtheinvisiblecow.com) - 音だけを頼りに隠れた牛を探します。
- [skribbl.io](https://skribbl.io) - 交代でお題を描き、ほかの人が早押しで当てます。
- [Draw a Stickman](https://www.drawastickman.com) - あなたの絵が短い冒険の主人公になります。
