# Awesome Websites to Explore [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> 值得消磨一个闲暇午后的网络小角落：玩具、游戏、奇趣网站、世界实况和读物。

这里的一切都能在普通浏览器中使用，无需注册即可开始，试用不花一分钱。这些网站大多出自一个人或小团队之手；如果哪个让你着迷，不妨告诉他们。

## 精选推荐

- [Aubergine](https://github.com/thirstyeggplant/aubergine) - 在浏览器中把所有终端放在一块画布上，并排运行多个编程智能体，看看哪个在等你。*（由本列表的维护者开发。）*

<a id="take-me-somewhere-random"></a>
## 随便带我去个地方

按一下按钮，就会落到一个从没见过的网站。StumbleUpon 的精神在这些网站中延续。

- [Cloudhiker](https://cloudhiker.net) - 随机跳到一个精选网站，想控制方向的话还可以选分类。
- [The Useless Web](https://theuselessweb.com) - 一个按钮，把你带到一个只讲一个笑话的网站。
- [Viralwalk](https://www.viralwalk.com) - 按心情筛选，把你传送到奇怪、漂亮或被半遗忘的网页。
- [Marginalia Explore](https://marginalia-search.com/explore) - 漫游一个专注于安静网络的搜索引擎所发现的小型个人网站。
- [Kagi Small Web](https://kagi.com/smallweb) - 每次展示一篇来自独立博客的最新文章。
- [indieblog.page](https://indieblog.page) - 带你去个人博客上的随机一篇文章。
- [Wiby](https://wiby.me) - 专门搜索简单老式网页的搜索引擎，带有“给我惊喜”按钮。
- [Neocities Browse](https://neocities.org/browse) - 现代版 GeoCities 上的成千上万个自制网站，可按标签或最近更新浏览。
- [MapCrunch](https://www.mapcrunch.com) - 把你随机放到地球上任意一个街景地点。

<a id="interactive-toys-and-explainers"></a>
## 互动玩具与图解

- [Neal.fun](https://neal.fun) - 关于尺度、金钱、太空和互联网的趣味项目，比如一路向下滚动到海洋最深处。
- [The Pudding](https://pudding.cool) - 用可交互的数据回答奇特问题的可视化文章。
- [Bartosz Ciechanowski](https://ciechanow.ski) - 讲解手表、相机和发动机原理的长文，配有可以旋转和拆解的模型。
- [Nicky Case](https://ncase.me) - 关于信任、焦虑、投票等难懂概念的小型可玩讲解。
- [Explorable Explanations](https://explorabl.es) - 一个通过拖动操作来学习的文章目录。
- [Orb.Farm](https://orb.farm) - 一个由你布置并维持生态的小水族箱。
- [Thisissand](https://thisissand.com) - 把彩色沙子倒成缓慢堆叠的层层风景。
- [Silk](http://weavesilk.com) - 用鼠标画出发光的对称图案。
- [Zen Photon Garden](https://zenphoton.com) - 摆放镜子和墙壁，看光线来回反射。
- [WebGL Fluid Simulation](https://paveldogreat.github.io/WebGL-Fluid-Simulation/) - 用手指或鼠标搅动明亮的流体。
- [Falstad applets](https://www.falstad.com/mathphysics.html) - 可以动手玩的物理和电子学，从波到电路。
- [Koalas to the Max](https://www.koalastothemax.com) - 鼠标悬停把圆不断分裂，直到出现一幅图。
- [The Scale of the Universe 2](https://htwins.net/scale2/) - 从已知最小的东西一路缩放到整个宇宙的尺度。
- [Experiments with Google](https://experiments.withgoogle.com) - 数百个关于代码、AI、音乐和地图的浏览器实验。
- [VOLE.wtf](https://vole.wtf) - 一个富有创意的工作室做的一堆傻乎乎的小游戏和玩具。

<a id="travel-from-your-chair"></a>
## 坐在椅子上去旅行

- [Radio Garden](https://radio.garden) - 转动地球仪，停在哪里就收听哪里的本地电台直播。
- [WindowSwap](https://www.window-swap.com) - 在陌生人的窗前待上几分钟，看看你永远不会去的城市或村庄。
- [Drive & Listen](https://drivenlisten.com) - 看着城市街道的行车视频，同时收听当地电台。
- [Virtual Vacation](https://virtualvacation.us) - 通过视频步行、驾车或飞越城市，或者观看实时摄像头。
- [Yamanote.fun](https://yamanote.fun) - 乘坐东京山手线的声音，一站接一站。
- [Cities and Memory](https://citiesandmemory.com) - 一张实地录音世界地图，每段录音都配有艺术家的再创作。
- [Street View Fun](https://www.streetviewfun.com) - 地图采集车拍到的最奇怪的东西。
- [Atlas Obscura](https://www.atlasobscura.com) - 世界各地的奇特地点，附地图和介绍。
- [The True Size Of](https://thetruesize.com) - 在地图上拖动国家，看看地图投影如何扭曲它们的大小。

<a id="the-planet-and-the-sky-live"></a>
## 实时的地球与天空

- [earth :: nullschool](https://earth.nullschool.net) - 实时显示风、洋流和空气质量的动态地球。
- [Windy](https://www.windy.com) - 风、雨、浪和风暴的实时天气地图。
- [LightningMaps](https://www.lightningmaps.org) - 实时显示正在发生的闪电。
- [Flightradar24](https://www.flightradar24.com) - 此刻正在空中的飞机，点击即可跟踪。
- [Stellarium Web](https://stellarium-web.org) - 任意时刻你所在位置上空的夜空。
- [NASA's Eyes](https://eyes.nasa.gov) - 在 3D 中与航天器和行星一同飞行。
- [meow.camera](https://meow.camera) - 中国各地猫粮喂食器上的直播摄像头，常有饥饿的访客光顾。

<a id="music-and-sound"></a>
## 音乐与声音

- [Chrome Music Lab](https://musiclab.chromeexperiments.com) - 让乐理变得可见的简单乐器和实验。
- [Typatone](https://typatone.com) - 你输入的每个字母都会奏出一个音符。
- [Patatap](https://patatap.com) - 每个按键都会播放一段声音和动画。
- [Incredibox](https://www.incredibox.com) - 把声音拖到 beatbox 小队身上，组合成一首曲子。
- [Multiplayer Piano](https://multiplayerpiano.com) - 和陌生人在同一个房间里弹钢琴。
- [Online Sequencer](https://onlinesequencer.net) - 在网格上作曲并分享。
- [Every Noise at Once](https://everynoise.com) - 数千种音乐流派的地图，每种都附有试听。
- [Radiooooo](https://radiooooo.com) - 选择一个国家和一个年代，听听当时那里流行什么。
- [Music-Map](https://www.music-map.com) - 输入一个乐队，看看谁的风格和他们相似。
- [Gnoosic](https://www.gnoosic.com) - 说出三个你喜欢的乐队，它会推荐第四个。
- [myNoise](https://mynoise.net) - 数百种可以用滑块调节的背景音景。
- [A Soft Murmur](https://asoftmurmur.com) - 混合雨声、风声、火声和咖啡馆的声音。
- [Rainy Mood](https://rainymood.com) - 雨声和雷声，仅此而已。
- [lofi.cafe](https://lofi.cafe) - 循环动画配上轻松的节拍。
- [musicForProgramming();](https://www.musicforprogramming.net) - 为专注而制作的长篇混音。

<a id="quick-games"></a>
## 小游戏

- [GeoGuessr](https://www.geoguessr.com) - 猜一张街景照片拍摄于世界何处；最初的版本，部分功能付费。
- [WorldGuessr](https://www.worldguessr.com) - 免费的街景猜地点游戏。
- [TimeGuessr](https://timeguessr.com) - 猜一张照片拍摄的地点和年份。
- [Globle](https://globle-game.com) - 根据每次猜测的距离，找出当天的神秘国家。
- [Contexto](https://contexto.me) - 根据猜测词与答案的语义接近程度，找出秘密单词。
- [Wiki Speedruns](https://wikispeedruns.com) - 只靠链接，从一篇维基百科文章竞速到另一篇。
- [The Endless Museum](https://theendlessmuseum.com) - 把维基百科当作 3D 博物馆漫步，每个链接都是一扇门。
- [Little Alchemy 2](https://littlealchemy2.com) - 组合元素，发现上百种事物。
- [Cookie Clicker](https://orteil.dashnet.org/cookieclicker/) - 点击一块饼干，然后建立一个替你点击的帝国。
- [Kittens Game](https://kittensgame.com) - 一款慢节奏的文字游戏，经营一个猫咪村庄。
- [Akinator](https://en.akinator.com) - 想一个人，精灵会通过是非题猜出是谁。
- [Find the Invisible Cow](https://findtheinvisiblecow.com) - 只凭声音找出藏起来的奶牛。
- [skribbl.io](https://skribbl.io) - 轮流画出一个秘密词语，其他人抢着猜。
- [Draw a Stickman](https://www.drawastickman.com) - 你画的小人会成为一段小冒险的主角。

<a id="draw-and-make-things"></a>
## 画画与创作

- [AutoDraw](https://www.autodraw.com) - 随手涂鸦，它会推荐更规整的图画。
- [Quick, Draw!](https://quickdraw.withgoogle.com) - 机器在倒计时中尝试猜出你在画什么。
- [Kleki](https://kleki.com) - 浏览器标签页里的免费绘画程序。
- [JS KidPix](https://kidpix.app) - 那款欢乐的儿童绘画程序，为网页重新打造。
- [Streetmix](https://streetmix.net) - 逐条车道设计一条街：自行车、树木、公交、长椅。
- [Everyone Draw](https://everyonedraw.com) - 一块共享的无限像素画布。
- [Wplace](https://wplace.live) - 和所有人一起在世界地图上画像素画。

## 光荣地毫无意义

- [Pointer Pointer](https://pointerpointer.com) - 找到一张有人指着你鼠标指针的照片。
- [Staggering Beauty](http://www.staggeringbeauty.com) - 晃动那条虫子。再用力一点。
- [Zombo.com](https://www.zombo.com) - 一句永远到不了任何地方的著名欢迎词。
- [Eel Slap](https://eelslap.com) - 就是字面意思。
- [Cat Bounce](https://cat-bounce.com) - 弹跳的猫。
- [Nyan Cat](https://www.nyan.cat) - 拖着彩虹的猫，永不停歇。
- [Popcat](https://popcat.click) - 点击猫咪，为你的国家增加计数。
- [Is It Christmas?](https://isitchristmas.com) - 一年中的每一天都回答同一个问题。
- [Is My Computer On?](https://ismycomputeron.com) - 回答另一个问题。
- [Has the Large Hadron Collider Destroyed the World Yet?](http://hasthelargehadroncolliderdestroyedtheworldyet.com) - 一个让人安心的状态页面。
- [Bouncing DVD Logo](https://www.bouncingdvdlogo.com) - 等它撞上角落。
- [Pixels Fighting](https://pixelsfighting.com) - 两种颜色争夺屏幕。
- [Smash the Walls](https://smashthewalls.com) - 和所有在线的人一起砸墙。
- [Passive Aggressive Passwords](https://www.trypap.com) - 一个对你有意见的密码检查器。

<a id="made-by-a-machine"></a>
## 机器制造

- [This Person Does Not Exist](https://www.thispersondoesnotexist.com) - 每次加载都有一张新虚构的人脸。
- [Which Face Is Real?](https://www.whichfaceisreal.com) - 从两张照片中挑出真实的那张。
- [This Word Does Not Exist](https://thisworddoesnotexist.com) - 虚构的单词，配上一本正经的释义。
- [InspiroBot](https://inspirobot.me) - 很快就变得奇怪的励志海报。
- [Library of Babel](https://libraryofbabel.info) - 所有可能的文本页面都已写好，等待被搜索。

<a id="questions-to-argue-about"></a>
## 值得争论的问题

- [Moral Machine](https://www.moralmachine.net) - 当每个选择都会伤害某人时，决定自动驾驶汽车该怎么做。
- [Philosophy Experiments](https://philosophyexperiments.com) - 测试你道德和逻辑直觉的简短互动测验。
- [Any Human Ever](https://anyhumanever.com) - 从所有曾经活过的人中随机抽取一个人生。

## 假装在工作

- [Hacker Typer](https://hackertyper.net) - 乱敲键盘，看起来像电影里的黑客。
- [GeekTyper](https://geektyper.com) - 更多黑客屏幕，还有多种主题。
- [FakeUpdate](https://fakeupdate.net) - 一个永远不会结束的全屏系统更新。
- [LookingBusy](https://www.lookingbusy.com) - 满屏的假仪表盘和消息。

<a id="the-old-web"></a>
## 旧时的网络

- [Windows 93](https://www.windows93.net) - 一个藏满隐藏程序的恶搞操作系统。
- [98.js](https://98.js.org) - 在浏览器中重现的 Windows 98，包括画图和扫雷。
- [Cameron's World](https://www.cameronsworld.net) - 1990 年代 GeoCities 页面的拼贴。
- [Space Jam (1996)](https://www.spacejam.com/1996/) - 一部电影的官网，至今保持 1996 年的原样在线。
- [OldWeb.today](https://oldweb.today) - 在模拟运行的老浏览器中浏览存档网页。
- [The Old Net](https://theoldnet.com) - 按所选年份浏览网站当年的样子。
- [Web Design Museum](https://www.webdesignmuseum.org) - 知名网站和应用几十年来的外观变化。
- [Flash Museum](https://flashmuseum.org) - 数千款 Flash 游戏和动画，重新可以玩了。
- [My90sTV](https://90s.myretrotvs.com) - 换台浏览 1990 年代的电视，连广告也有。
- [Internet Archive](https://archive.org) - 网络的记忆，还有老书、老电影和可运行的旧软件。

<a id="rabbit-holes-to-read"></a>
## 读起来停不下来

- [随机维基百科文章](https://en.wikipedia.org/wiki/Special:Random) - 从任何地方开始。
- [Damn Interesting](https://www.damninteresting.com) - 来自科学和历史的长篇真实故事。
- [The Public Domain Review](https://publicdomainreview.org) - 介绍过去那些奇异而美丽、如今人人可再利用的作品的文章。
- [Open Culture](https://www.openculture.com) - 免费课程、电影、有声书和讲座。
- [kottke.org](https://kottke.org) - 自 1998 年起每日更新的艺术、科学和设计链接博客。
- [Nestflix](https://nestflix.fun) - 收录出现在真实影视作品中的虚构电影和节目的目录。
