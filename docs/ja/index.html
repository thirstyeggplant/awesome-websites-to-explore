のんびりした午後にぴったりの Web の小さな片隅：おもちゃ、ゲーム、珍品、世界のライブ映像、読みもの。

注目： Aubergine - ブラウザの 1 枚のキャンバスにすべてのターミナルを置き、複数のコーディングエージェントを並べて動かし、どれがあなたを待っているかを確認できます。（このリストの管理者が開発しています。）

どれも普通のブラウザで動き、アカウントなしで始められ、無料で試せます。ほとんどは個人や小さなチームが作ったサイトです。気に入ったら作者に伝えてあげてください。

どこかへ連れていって

ボタンを押せば、見たことのないサイトへ。StumbleUpon の精神はここに生きています。

  • Cloudhiker - 厳選されたサイトにランダムで飛びます。行き先を絞りたいならカテゴリも選べます。
  • The Useless Web - ボタン 1 つで、ネタ 1 つだけのサイトに飛ばされます。
  • Viralwalk - 気分で絞り込んで、奇妙なページ、きれいなページ、忘れられかけたページへワープ。
  • Marginalia Explore - 静かな Web 専門の検索エンジンが見つけた小さな個人サイトを巡ります。
  • Kagi Small Web - 独立系ブログの最新記事を 1 つずつ表示します。
  • indieblog.page - 個人ブログのランダムな記事へ連れていきます。
  • Wiby - シンプルで昔風のページ専門の検索エンジン。「びっくりさせて」ボタン付き。
  • Neocities Browse - 現代版 GeoCities にある何千もの手作りサイト。タグ別や最近の更新順で見られます。
  • MapCrunch - 地球上のどこかのストリートビュー地点にランダムで降ろします。

インタラクティブなおもちゃと解説

  • Neal.fun - スケール、お金、宇宙、インターネットをテーマにした遊び心あるプロジェクト。海の最深部までスクロールするものなど。
  • The Pudding - 触って確かめられるデータで、ちょっと変わった疑問に答えるビジュアルエッセイ。
  • Bartosz Ciechanowski - 時計、カメラ、エンジンの仕組みを解説する長文記事。回したり分解したりできるモデル付き。
  • Nicky Case - 信頼、不安、投票など難しい考えを、遊びながら理解できる小さな解説。
  • Explorable Explanations - ものを動かしながら学べるエッセイのディレクトリ。
  • Orb.Farm - 生き物を入れて維持する小さな水槽。
  • Thisissand - 色とりどりの砂を注いで、ゆっくり層になる風景を作ります。
  • Silk - ポインターで光る対称模様を描きます。
  • Zen Photon Garden - 鏡と壁を置いて、光が跳ね返る様子を眺めます。
  • WebGL Fluid Simulation - 指やマウスで鮮やかな流体をかき混ぜます。
  • Falstad applets - 波から回路まで、遊びながら触れる物理と電子工作。
  • Koalas to the Max - マウスを乗せて円を分割していくと、絵が浮かび上がります。
  • The Scale of the Universe 2 - 知られている最小のものから宇宙の大きさまでズーム。
  • Experiments with Google - コード、AI、音楽、地図を使った何百ものブラウザ実験。
  • VOLE.wtf - 発想豊かなスタジオが作った、ばかばかしい小さなゲームとおもちゃの山。

椅子に座ったまま旅をする

  • Radio Garden - 地球儀を回して、止まった場所の地元ラジオを生で聴けます。
  • WindowSwap - 行くことのない街や村で、見知らぬ誰かの窓辺にしばし佇む。
  • Drive & Listen - 地元のラジオを流しながら、街の通りを動画でドライブ。
  • Virtual Vacation - 動画で街を歩き、走り、飛び回る。ライブカメラも見られます。
  • Yamanote.fun - 東京の山手線に乗っている音を、駅ごとに。
  • Cities and Memory - フィールド録音の世界地図。それぞれにアーティストによるリワークが添えられています。
  • Street View Fun - 地図撮影車が捉えた最も奇妙なもの。
  • Atlas Obscura - 世界中の不思議な場所を、地図と解説で。
  • The True Size Of - 国を地図上でドラッグして、図法による大きさの歪みを確かめます。

地球と空をライブで

  • earth :: nullschool - 今この瞬間の風、海流、大気質を表示するアニメーション地球儀。
  • Windy - 風、雨、波、嵐のライブ気象マップ。
  • LightningMaps - 落雷がリアルタイムで表示されます。
  • Flightradar24 - 今飛んでいる飛行機。クリックで追跡できます。
  • Stellarium Web - どこでも、いつでも、その場所の夜空。
  • NASA's Eyes - 3D で探査機や惑星と一緒に飛べます。
  • meow.camera - 中国の猫用給餌器のライブカメラ。お腹をすかせた来客が立ち寄ります。

音楽とサウンド

  • Chrome Music Lab - 音楽理論を目に見える形にするシンプルな楽器と実験。
  • Typatone - タイプした文字ごとに音が鳴ります。
  • Patatap - キーを押すごとに音とアニメーションが流れます。
  • Incredibox - ビートボックス隊に音をドラッグして曲を作ります。
  • Multiplayer Piano - 知らない人たちと同じ部屋でピアノを弾く。
  • Online Sequencer - グリッド上で曲を作って共有できます。
  • Every Noise at Once - 何千もの音楽ジャンルの地図。それぞれ試聴付き。
  • Radiooooo - 国と年代を選んで、そこで流れていた音楽を聴く。
  • Music-Map - バンド名を入れると、似た音のアーティストがわかります。
  • Gnoosic - 好きなバンドを 3 つ挙げると、4 つ目を提案してくれます。
  • myNoise - スライダーで調整できる何百もの環境音。
  • A Soft Murmur - 雨、風、焚き火、カフェの音をミックス。
  • Rainy Mood - 雨と雷、それだけ。
  • lofi.cafe - ループするアニメーションにゆったりしたビート。
  • musicForProgramming(); - 集中するための長いミックス。

すぐ遊べるゲーム

  • GeoGuessr - ストリートビューの写真が世界のどこで撮られたかを当てる元祖。一部有料。
  • WorldGuessr - ストリートビューで場所を当てる無料版。
  • TimeGuessr - 写真が撮られた場所と年を当てます。
  • Globle - 推測がどれだけ近いかを手がかりに、その日の謎の国を探します。
  • Contexto - 意味の近さを手がかりに、秘密の単語を見つけます。
  • Wiki Speedruns - リンクだけを使って、Wikipedia の記事から記事へ競争。
  • The Endless Museum - リンクが扉になった 3D 美術館として Wikipedia を歩きます。
  • Little Alchemy 2 - 要素を組み合わせて何百ものものを発見。
  • Cookie Clicker - クッキーをクリックし、やがて代わりにクリックしてくれる帝国を築きます。
  • Kittens Game - 猫の村を育てる、ゆっくりしたテキストゲーム。
  • Akinator - 誰かを思い浮かべると、魔人がはい・いいえの質問で当てます。
  • Find the Invisible Cow - 音だけを頼りに隠れた牛を探します。
  • skribbl.io - 交代でお題を描き、ほかの人が早押しで当てます。
  • Draw a Stickman - あなたの絵が短い冒険の主人公になります。

描く・作る

  • AutoDraw - 落書きすると、きれいな絵を提案してくれます。
  • Quick, Draw! - 制限時間内に、機械があなたの絵を当てようとします。
  • Kleki - ブラウザのタブで使える無料のペイントソフト。
  • JS KidPix - あの陽気な子ども向けお絵かきソフトを Web 向けに再構築。
  • Streetmix - 自転車、木、バス、ベンチ。車線ごとに通りをデザイン。
  • Everyone Draw - みんなで使う、終わりのないピクセルキャンバス。
  • Wplace - 世界中の人と一緒に、世界地図にドット絵を描きます。

見事に無意味

  • Staggering Beauty - ミミズを揺らそう。もっと激しく。
  • Zombo.com - どこにもたどり着かない有名な歓迎ページ。
  • Eel Slap - 名前のとおりです。
  • Cat Bounce - 猫が、跳ねる。
  • Nyan Cat - 虹を引く猫が、永遠に。
  • Popcat - 猫をクリックして、自分の国のカウントを増やそう。
  • Is It Christmas? - 1 年中毎日、1 つの質問に答えます。
  • Is My Computer On? - 別の質問に答えます。
  • Has the Large Hadron Collider Destroyed the World Yet? - 安心できるステータスページ。
  • Bouncing DVD Logo - 角に当たる瞬間を待ちましょう。
  • Pixels Fighting - 2 色が画面を取り合います。
  • Smash the Walls - オンラインのみんなと一緒に壁を壊します。
  • Passive Aggressive Passwords - あなたについて一言ある、パスワードチェッカー。

機械が作ったもの

  • This Person Does Not Exist - 読み込むたびに新しい架空の顔。
  • Which Face Is Real? - 2 枚のうち本物の写真を選びます。
  • This Word Does Not Exist - 自信満々の定義が付いた造語。
  • InspiroBot - すぐにおかしな方向へ行く自己啓発ポスター。
  • Library of Babel - ありとあらゆるテキストのページがすでに書かれ、検索されるのを待っています。

議論したくなる問い

  • Moral Machine - どの選択も誰かを傷つけるとき、自動運転車はどうすべきかを決めます。
  • Philosophy Experiments - 道徳と論理の直感を試す短いインタラクティブなテスト。
  • Any Human Ever - これまでに生きたすべての人から、ひとつの人生をランダムに選びます。

仕事しているふり

  • Hacker Typer - キーボードを適当に叩くだけで映画のハッカー気分。
  • GeekTyper - テーマ付きのハッカー画面をさらに。

昔の Web

  • Windows 93 - 隠しプログラムだらけのジョーク OS。
  • 98.js - ペイントやマインスイーパー付きで、ブラウザに再現された Windows 98。
  • Cameron's World - 1990 年代の GeoCities ページのコラージュ。
  • Space Jam (1996) - 1996 年当時のまま今も公開されている映画の公式サイト。
  • OldWeb.today - エミュレーションで動く古いブラウザで、アーカイブされたページを閲覧。
  • The Old Net - 選んだ年当時の姿でサイトを訪れます。
  • Web Design Museum - 有名なサイトやアプリが数十年でどう変わってきたか。
  • Flash Museum - 何千もの Flash ゲームとアニメが再び遊べます。
  • My90sTV - CM も含めて 1990 年代のテレビをザッピング。
  • Internet Archive - Web の記憶。古い本や映画、動かせるソフトウェアも。

読みふけるウサギの穴

  • おまかせ Wikipedia 記事 - どこからでも始めよう。
  • Damn Interesting - 科学と歴史にまつわる長い実話。
  • The Public Domain Review - 誰でも再利用できるようになった、過去の奇妙で美しい作品についてのエッセイ。
  • Open Culture - 無料の講座、映画、オーディオブック、講義。
  • kottke.org - 1998 年から続く、アート・科学・デザインのリンクを毎日紹介するブログ。
  • Nestflix - 実在の作品の中に登場する架空の映画や番組のカタログ。
